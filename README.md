# Takomo fitting: phone measurements

Browser prototypes for the Since AI Hackathon 2026 (Takomo Golf challenge). MediaPipe runs on the device;
photos and video never leave it.

- `index.html`: wrist-to-floor from a full-body camera view or photo (scale from the golfer's height).
- `hand.html`: hand length from a photo next to a bank card → grip size.

Accuracy is still being checked against a tape measure.
